## Concept

A single `.md` file with YAML frontmatter (`type` required) and a markdown body.
The atomic unit of knowledge in an OKF bundle.

## Concept path

The bundle-qualified path without the `.md` extension (e.g. `retail/tables/orders`).
Serves as a concept's unique identity; the first segment names the bundle.

## index.md

A reserved OKF file that enumerates a directory's contents. Regenerated by
Cortex during ingest.
